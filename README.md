# Kdan 抽獎系統

## 介紹
這是一個基於 Next.js 開發的抽獎系統，可以讓用戶自行設定獎項與抽出的數量，並且具備中獎剔除等功能，適合用於企業活動、尾牙或社群互動。

---

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
```

## 功能

- **新增獎項名稱**：
  支援為每輪抽獎新增專屬的獎項名稱，方便管理和記錄。
- **新增抽獎人員**：
  用戶可以輸入參與抽獎的人員名稱，並使用半形逗號（`,`）分隔多個項目。例如：`王大明,李大頭`。
- **連續獎項抽獎流程**：
  加入 sequential prize queue，能新增多個獎項、調整順序、每輪抽完自動推進下一個，避免一次只能抽一種獎項。
- **剔除中獎者**：
  中獎名單中若已有相同項目被抽出，在下一次抽獎時將不會再被選中。
- **排除名單控制**：
  側邊欄新增排除名單輸入欄，抽獎前就會自動從名單中剔除指定人員（搭配「去除重複得獎名單」開關），不需另外送出或手動處理。
- **顯示得獎名單**：
  即時展示已抽出的得獎名單，並紀錄中獎的時間與對應的獎項名稱，方便查看和統計。
- **刪除得獎名單**：
  支援一鍵清空得獎名單，重新開始抽獎。
- **複製得獎名單**：
  提供快速複製功能，方便將結果貼上到其他平台。
- **復原與數量 guard**：
  抽完一輪後可用 Ctrl/Cmd+Z 復原上一輪得獎、回補名單；抽獎時會檢查剩餘候選人數是否足夠預定人數，若不足就會提示並中止，防止少於預定人數仍繼續跑。
